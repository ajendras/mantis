## [0.1.0] - 2026-11-20

### Added

- Smart Triage — Analyzes new issues and suggests accurate labels, priority, and assignee using your project's history
- Duplicate Detector — Finds semantically similar past issues and surfaces the most relevant resolutions
- PR Reviewer — Generates contextual code reviews with line-specific comments and security notes
- Reply Assistant — Draft replies to common questions while respecting your project's tone and policies
- Doc Auditor — Scans README and docs for outdated sections or missing information after changes
- Rule Engine — Lets you define custom automation rules that the LLM respects on every run
- Weekly Digest — Produces concise markdown reports of activity, decisions and suggested next steps
- Local-first — Works offline with Ollama, LM Studio or any OpenAI-compatible local endpoint
